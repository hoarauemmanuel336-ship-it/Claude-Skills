# Claude Learning Skills

Five Claude skills for learning any subject with the AI. Each one produces a self-contained, dark, dense HTML page that you open in your browser, on a computer or a phone, and that you can pass on as is to anyone who wants to learn.

| Skill | What it makes |
|---|---|
| **study-path** | A full study plan for a subject: blocks, themes and topics to check off, saved progress, and one-tap copying of any topic to ask the AI for a book, a diagram, a course or an article on it. |
| **html-book** | A long text (book, essay, guide) with a side table of contents, three scopes and three depths of reading, citable pagination and quote cards. |
| **html-course** | An introductory course split into pages: lessons, boxes, exercises with solutions, self-assessment, a capstone, review sheets and a glossary. |
| **interactive-diagrams** | An interactive overview of a subject: collapsible sections, cards that unfold their explanation on click, bifurcation, tension and timeline layouts. |
| **phrases-to-remember** | A definition plus one phrase per major part, to memorize and say out loud, shown in a page where you check the ones to rewrite. |

## How they fit together

Start with **study-path** to map the subject, then copy each topic and ask for it as a book, a course or a diagram. Use **phrases-to-remember** to keep the essentials in mind.

## Installation

Each folder is a skill. Zip a folder and upload it in Claude (Settings → Capabilities → Skills), or copy it into your skills directory in Claude Code. Every skill keeps its `engine/` folder next to its `SKILL.md`: the AI writes only the content, and the engine assembles the page.

Content is written in the language of the user; the interface labels are in English.
